# oleksandrkosovan.github.io

Personal academic portfolio site for Oleksandr Kosovan, hosted on GitHub Pages.

Live at: https://oleksandrkosovan.github.io

## Structure

Static HTML/CSS, no build step — each page is a standalone `.html` file sharing `styles.css` and the same header/nav markup.

- `index.html` — About
- `publications.html` — Publications
- `experience.html` — Academic & industry experience
- `teaching.html` — Teaching
- `collaborators.html` — Collaborators & interns
- `talks.html` — Talks
- `services.html` — Services (PC/reviewing/committee work)
- `slides.html` — Slides
- `press.html` — Press & Awards
- `images/`, `pdf/` — assets

## Editing

Copy an existing entry block in the relevant page and edit it in place to keep markup/classes consistent. Newest entries go first. If you add a nav item, add it to every page's nav list.
